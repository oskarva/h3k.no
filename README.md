# h3k.no — Lysfabriken

Statisk nettsted laget for GitHub Pages. Sidene bruker vanlig HTML, CSS og
JavaScript og trenger ikke et byggesteg.

Historie- og produkttekstene i HTML-filene er bearbeidet fra kildetekstene i
`tekst/`.

## Innhold som fortsatt skal byttes ut

Søk etter `BYTT UT` og `BILDE` i HTML-filene for å finne alle
midlertidige tekster og bilder.

- Bytt `images/placeholder-gruppe.svg` i `index.html` med et ekte gruppebilde.
- Bytt `images/placeholder-portrett.svg` i `kurs.html` med kontaktpersonens portrett.
- Bytt de midlertidige utsnittene av `images/h3kstortoglite.jpg` med separate
  produktbilder for Stort H3k og Lite H3k når de er klare.
- Oppdater kursdato, kursbeskrivelse, telefon og e-post i `kurs.html`.

Husk å oppdatere bildebeskrivelsen (`alt`) når et plassholderbilde erstattes.

## Lokal forhåndsvisning

Kjør for eksempel `python3 -m http.server` i prosjektmappen og åpne adressen
som vises i terminalen. Den samme relative filstrukturen brukes av GitHub Pages.
